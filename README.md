# CopyLink---website
Site institucional desenvolvido para a CopyLink -- Copiadora &amp; Serviços Gráficos. HTML, CSS puro e seguindo a abordagem Mobile First.

📋 Sobre o Projeto
O site foi criado para apresentar os serviços da CopyLink de forma clara e profissional, com foco em usabilidade mobile e identidade visual da marca.

📄 Páginas

index.html — Página inicial com hero section e chamada para ação.
servicos.html — Listagem completa dos 14 serviços oferecidos.
contatos.html — Informações de contato, endereço e horário de funcionamento.


🛠️ Tecnologias Utilizadas
#OBS: Por ser um site simples, não houve necessidade da utilização de JavaScript e Framework. Foram usados somente HTML e CSS visando a velocidade do site para a proposta pedida.

HTML5
CSS3 (Mobile First) 

📱 Responsividade
O projeto foi desenvolvido com a metodologia Mobile First, garantindo uma boa experiência em todos os dispositivos:

📱 Mobile (360px+)
📟 Tablet (768px+)
🖥️ Desktop (1024px+)
